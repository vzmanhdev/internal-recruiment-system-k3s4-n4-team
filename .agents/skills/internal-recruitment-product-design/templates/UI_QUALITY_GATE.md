# UI Quality Review Checklist

## Information architecture
- [ ] Page has one clear business purpose
- [ ] Navigation is role-appropriate
- [ ] No developer-only items in end-user navigation
- [ ] KPIs are relevant to the current page
- [ ] Dynamic workflows are not hardcoded in labels

## Visual hierarchy
- [ ] Consistent app shell
- [ ] Clear title / section / body hierarchy
- [ ] White-first surface with restrained blue
- [ ] Consistent spacing/radius/shadow tokens
- [ ] No emoji navigation icons
- [ ] One dominant CTA per section
- [ ] Status badges compact and semantic

## Data UX
- [ ] Search/filter structure is useful
- [ ] Table density is appropriate
- [ ] Pagination present when required
- [ ] Loading state
- [ ] Empty state
- [ ] Error/retry state
- [ ] Permission-denied state
- [ ] No production hardcoded business data

## Responsive/accessibility
- [ ] 360px usable
- [ ] Keyboard accessible
- [ ] Visible focus
- [ ] Form labels
- [ ] Color not sole status indicator
- [ ] Dialog focus/close behavior valid

## SEO
- [ ] Public career/job pages have metadata/canonical/structured data as applicable
- [ ] Public pages are performant and crawlable
- [ ] Private/internal pages use noindex and are absent from sitemap
- [ ] Candidate private/status pages are not indexed
